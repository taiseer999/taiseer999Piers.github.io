Node icon sets — switched by AbukarimTools (Option A)
=====================================================
  extras/icons/         live set the nodes read (ships colored)
  extras/icons_color/   colored master

Do not delete icons/. Full coverage incl. Adventure/Family/Science Fiction, pea.png.
